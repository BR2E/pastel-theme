## [0.0.1] - Initial Release

### Added
* Initial release of the Pastel - Theme.
* Deep dark background (`#202130`) optimized for reduced eye strain during night-time coding sessions.
* Custom UI theming for the Activity Bar, Side Bar, Editor Line Numbers, and Status Bar to match the core aesthetic.
* Comprehensive pastel syntax highlighting tailored for major languages, including HTML, CSS, JavaScript, TypeScript, Python, JSON, and Markdown.
* Semantic token colors for better code readability (variables, functions, keywords, strings, and markup).
